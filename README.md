## Selected Work

### СПЕЦ-КП — Engineering Specification to Commercial Proposal
A Windows desktop application that extracts structured line items from engineering specification PDFs and prepares commercial proposal workbooks in Excel using a corporate template.

- PDF text extraction and OCR for scanned documents
- Optional AI-assisted review of ambiguous rows
- Human-in-the-loop validation and editing of extracted data
- Price-list import and rate matching
- Side-by-side PDF and structured item review
- Local document and settings storage

**Technology:** Python, FastAPI, PyMuPDF, Tesseract OCR, React, Vite, XLSX.

*The project was delivered for a customer. Source code and customer materials are not published.*

### XPROAI — AI-powered marketing automation
A SaaS product direction focused on automating end-to-end social media marketing workflows, including research, content production, and connected processes.

**Focus:** SaaS product architecture, AI-assisted content workflows, automation, and integrations.

[Project website](https://xproai.ru)

### Multi-agent legal research and academic writing system
A multi-stage agentic workflow for legal research and drafting academic articles, including source discovery, knowledge retrieval, coordinated agent tasks, and review stages.

**Focus:** multi-agent orchestration, retrieval-augmented generation (RAG), knowledge bases, and quality-control workflows.

### LLM chat and model orchestration platform
A SaaS-style chat interface that combines conversational memory with adaptive model selection based on the user's request.

**Focus:** LLM routing, conversational context, API integration, and product UX.

### Client web products and automations
Websites and customer-facing automation systems for businesses, including furniture and renovation services, gift-catalog experiences, and messaging bots for Telegram and MAX.

*Commercial implementations are presented at a high level to respect customer confidentiality.*
